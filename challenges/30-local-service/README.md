# 30 — локальная модель как свой сервис

Сервис — уже существующий API стенда. Браузер не ходит на `:11435`.

1. `PUT /api/v1/me/llm-sources` с адресом M1. Ответ без ключа и без полного URL.
2. Три успешных вызова с пином `ollama/qwen36-fast:latest`.
3. Сообщение длиннее `max_message_chars` (8000) → 422.
4. Пачка сверх `LOCAL_LLM_REQUESTS_PER_HOUR` (30) → 429 и текст «Слишком много запросов подряд. Подождите немного и напишите снова.»

На прод выкладывается через обычный rolling deploy; браузер по-прежнему не ходит на `:11435`.
