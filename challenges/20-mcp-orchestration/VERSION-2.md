# День 20 · версия 2 — чат спрашивает сервер «Модели»

Старая версия: **Разбор смены** по серверам `watch → models → brief`. Её не удаляем.

Вторая версия: живой выбор в чате — это узкий маршрут только на сервер **models** (`model_pulse`). Сыплющиеся из `attention` попадают в «не брать» и не кликаются.

## Что должно быть сделано

- Чипы «брать» / «не брать» размечены смыслом сервера моделей, не общим каталогом
- `attention` / высокий down_rate → disabled «не брать»
- Если в селекте уже сыплющаяся — текст «взять лидера»
- На MCP три плитки watch / models / brief и разбор смены остаются

## Что видно на видео, что это реализовано

1. В чате ряд **не брать** (или честная фраза «сыплющихся нет»)
2. Disabled-чип нельзя выбрать
3. `/?shell=mcp` → карточки серверов и **Разбор смены** с тегами `watch` / `models` / `brief`
4. Одно и то же имя `model_pulse` в чате и на сервере **models**
