# 27 — локальная модель в чате

1. Войти. Профиль → Подключения → «Подключить».
2. Адрес `http://100.90.210.109:11435`. Ключ пустой. Сохранить. Строка: «Подключено: 100.90.210.109. Моделей: N.» На кнопке нет «90 секунд».
3. Профиль → Модели: выбрать `ollama/qwen36-fast:latest`. «Авто» эту модель не выбирает.
4. В чат: «Запомни: имя Артем, язык Python. Ответь двумя строками Имя: и Язык:».
5. Пока нет первого токена, на пустом пузыре id, секунды и «Модель грузится, до 90 с.».
6. Бейдж ответа совпадает с пином. Строки `Имя: Артем` и `Язык: Python`.

Браузер ходит только в API стенда. Ollama вызывает сервер.
