# День 18 · версия 2 — пульс не разовый

Старая версия: **Сводка каждые 60 с**, job в SQLite, карточка сводки на MCP. Её не удаляем.

Вторая версия: в чате пульс можно **снять снова**. Это тот же периодический смысл: данные стареют, оператор обновляет, не пересобирая каталог.

## Что должно быть сделано

- Повторный **Снять пульс** перезапрашивает `model_pulse`
- Пока идёт запрос — в мета «снимаем…»
- Ночная вахта на MCP (`schedule_digest`, список заданий) жива как была

## Что видно на видео, что это реализовано

1. Полоска уже с чипами
2. Второй клик **Снять пульс** — короткий «снимаем…», чипы остаются/обновляются
3. Переключение на **MCP** → **Сводка каждые 60 с** / расписание на месте
4. Два экрана рядом по смыслу: чат обновляет выбор модели, вахта пишет сводку пока никого нет
