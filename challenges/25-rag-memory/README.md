# День 25 — Мини-чат: база + память задачи

**Цель:** отдельный мини-чат, где на каждый вопрос идёт поиск в базе, всегда видны источники, и не теряется цель разговора.

## Что сделать

Собери веб-чат (вкладка **База** / `?shell=rag`), который:

1. хранит **историю** сообщений  
2. на **каждый** вопрос ищет контекст в RAG  
3. отвечает с учётом найденного  
4. **всегда** показывает источники под ответом  
5. держит **память задачи** слева: цель · уточнения (facts) · ограничения  

Проверка устойчивости — **два** длинных сценария по **10–15** сообщений (цель не теряется к середине):

- тексты: [`SCENARIOS.md`](SCENARIOS.md)  
- прогон:  
  `python3 challenges/25-rag-memory/run.py --scenario a --limit 12`  
  `python3 challenges/25-rag-memory/run.py --scenario b --limit 12`
