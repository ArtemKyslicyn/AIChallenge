## Сценарий (~3–4 мин)

1. Вкладка **База** — полоска «Цель / facts / ограничения».
2. 3–4 вопроса из сценария A (:443 → nginx → model_id). Под каждым ответом — **Источники базы** + `model_id`.
3. Спросить «Напомни цель» — ассистент держит исходную цель.
4. **Новый сценарий** → 2–3 вопроса из сценария B (Guest MCP). Источники снова видны.
5. Коротко показать, что facts/ограничения накопились.

## Кадр-итог

История + источники на каждом ходе + цель/инварианты сбоку.
