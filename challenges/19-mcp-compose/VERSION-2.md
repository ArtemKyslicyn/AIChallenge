# День 19 · версия 2 — пульс → выбор → ответ

Старая версия: **Ночной бриф** search → summarize → saveToFile. Её не удаляем.

Продукт: три шага посетителя без JSON: выбрать живую → написать → увидеть `model_id` в пузыре.

## Что видно на видео

1. «Писать {модель}» → селект = этот id
2. Короткое сообщение → бейдж ответа совпадает (титр не закрывает пузырь)
3. MCP → запустить **Ночной бриф**, дождаться трёх `.mcp-call`

> Старые версии: handshake на вкладке MCP и карточка «Кому писать» в чате. Их не удаляем.  
> Продукт: посетитель вставляет адрес своего набора (iPhone, Android или git) в Настройках → Подключения и видит, что обычный чат умеет спрашивать уже его сервер. Не протокол — подключение и первый опыт у себя. Под ответом по-прежнему виден `model_id`.
