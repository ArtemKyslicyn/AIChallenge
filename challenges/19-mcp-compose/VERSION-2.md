# День 19 · версия 2 — цепочка «пульс → выбор → ответ»

Старая версия: **Ночной бриф** `search → summarize → saveToFile` на MCP. Её не удаляем.

Вторая версия: в чате короткий пайплайн для посетителя: **снять пульс → выбрать живую → отправить сообщение**. Три шага видны без JSON-стены.

## Что должно быть сделано

- Шаг 1: `model_pulse` собирает факты
- Шаг 2: человек (или «взять лидера») выбирает модель из «брать»
- Шаг 3: сообщение уходит с этим пином, в пузыре виден `model_id`
- Ночной бриф на MCP по-прежнему пишет файл

## Что видно на видео, что это реализовано

1. **Снять пульс** → ряд «брать»
2. Клик живой модели → чип `on`
3. Короткий текст в чат → ответ с тем же `model_id`, что на чипе
4. `/?shell=mcp` → **Ночной бриф** и три `.mcp-call` на месте
