# День 16 · версия 2 — чат спрашивает стенд, кому писать

Старая версия: `initialize` → `list_tools` на `/?shell=mcp`. Её не удаляем.

Продукт: посетитель открывает **Чат**. В пустом треде карточка **«Кому писать сейчас»** — стенд уже на связи и предлагает живую модель. Композитор не перекрыт.

## Что должно быть сделано

- Пустой чат показывает карточку с источником «пульс моделей · MCP models»
- Кнопка **Обновить пульс** не блокирует поле ввода
- Вкладка MCP и таблица инструментов дня 16 на месте

## Что видно на видео

1. Открыт Чат, в центре карточка, не пустое поле
2. Крупный id модели и кнопка «Писать …»
3. Вкладка MCP → `connected` и таблица tools (доскроллить, не останавливаться на вахте)
