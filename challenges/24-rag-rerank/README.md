# День 24 — Три режима базы: raw / filtered / full

**Цель:** после поиска по векторам сравнить три режима выдачи на одном вопросе и показать, что меняется в источниках.

## Что сделать

1. Чат → **Настройки** → включи «Использовать базу»
2. Один вопрос три раза (например: «что такое Guest MCP»), меняя **Режим базы**:

| Режим | Что делает |
|---|---|
| **raw** | взяли top кандидатов → обрезали до top_k |
| **filtered** | то же + отсечка по similarity (`min_score`) |
| **full** | переписали запрос → фильтр → rerank → top_k |

3. В блоке «Источники базы» должно быть видно: было N → стало K; в **full** — строка «Запрос после rewrite»
4. Рядом: **«Добавить в базу»** / **«Документы»** (свои загрузки — см. день 23)
