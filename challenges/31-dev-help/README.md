# Day 31 — Спросить по docs

**На сайте:** **Ассистент → По docs**

**Цель:** получить ответ по стенду только из handbook (живые docs), с цитатами.

## Что сделать

1. Открой **Ассистент** → карточку **По docs**
2. В цели: «Куда ходит публичный :443 на этом стенде?»
3. **Спросить в чате** → уходит `/help …`
4. В ответе: источники / «нет в базе» + `model_id`
