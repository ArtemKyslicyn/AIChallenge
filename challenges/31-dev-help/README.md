# Day 31 — Спросить по docs

**На сайте:** **Ассистент → По docs**

**Цель:** ответ по стенду только из handbook, с цитатами.

**Модель:** в селекторе по умолчанию локальная (`ollama/…` если подключена). Можно выбрать облако / Авто. Для сдачи курса — бейдж `ollama/…`.

## Что сделать

1. Профиль → Подключения → Local LLM (как дни 26–30)
2. **Ассистент → По docs** — убедись, что модель local (или выбери вручную)
3. Цель: «Куда ходит публичный :443 на этом стенде?»
4. **Спросить в чате** → `/help …`
5. Источники handbook + `model_id`
