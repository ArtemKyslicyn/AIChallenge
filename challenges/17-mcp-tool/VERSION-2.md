# День 17 · версия 2 — первая живая проба модели

Старая версия: кнопки **Проверить стенд** / **Рейтинг моделей** на `/?shell=mcp`, JSON `probe_stand` / `model_pulse`. Её не удаляем.

Вторая версия: тот же `model_pulse` кормит **выбор модели в чате**. Зритель видит не каталог tool, а «эти модели можно брать».

## Что должно быть сделано

- **Снять пульс** вызывает MCP-инструмент `model_pulse` (живые Pareto + жалобы)
- Ряд **брать** — модели с рейтингом
- Клик по чипу ставит `modelId` в селект композитора
- Ответ в чате по-прежнему несёт `model_id`

## Что видно на видео, что это реализовано

1. Клик **Снять пульс**
2. Зелёные чипы с короткими id (`deepseek-v4-flash` и т.д.)
3. Клик по чипу → чип в состоянии `on`, селект **Модель** меняется с «Авто» на выбранную
4. На `/?shell=mcp` по-прежнему есть **Проверить стенд** и `probe_stand` в таблице
