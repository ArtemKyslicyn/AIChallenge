# День 17 · версия 2 — выбор модели вместо JSON

Старая версия: **Проверить стенд** / `probe_stand` на MCP. Её не удаляем.

Продукт: тот же пульс кормит решение «кому писать». Клик **Писать {модель}** ставит пин. Селект **Модель** больше не «Авто».

## Что видно на видео

1. Карточка с лидером
2. Клик «Писать …» → селект показывает тот же id
3. MCP → нажать **Проверить стенд**, подержать ответ `probe_stand`

> Старые версии: handshake на вкладке MCP и карточка «Кому писать» в чате. Их не удаляем.  
> Продукт: посетитель вставляет адрес своего набора (iPhone, Android или git) в Настройках → Подключения и видит, что обычный чат умеет спрашивать уже его сервер. Не протокол — подключение и первый опыт у себя. Под ответом по-прежнему виден `model_id`.
