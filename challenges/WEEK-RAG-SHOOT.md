
После успеха: в каждом `RESULTS.md` ссылка на свежий mp4; для 23 убрать «видео после деплоя».

## Общие правила съёмки

1. Перед днём — **Новый чат** (кроме 25: `?shell=rag`).
2. Титр дня 5–7 с в начале (`showRecordCard`).
3. Пауза на ключевом UI ≤ 8–9 с; не крутить скролл без нужды.
4. Всегда читаемы: `model_id`, источники (раскрыты), tool-карточки (`rag_ingest` / `rag_list_documents`).
5. Цифры индекса / режимов — оверлей или `RESULTS`; терминал не снимать.
6. Провал одного дня → `RECORD_ONLY=<день>` ещё раз; остальные не перезаписывать без нужды.
