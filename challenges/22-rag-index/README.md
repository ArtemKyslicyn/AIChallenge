# День 22 — Индексация документов (две стратегии)

**Цель:** проиндексировать корпус знаний двумя способами чанкинга, сохранить метаданные и сравнить числа.

> Папка `22-rag-index` = **день 22**. День 21 — живой выбор модели (`21-live-models`).

## Что сделать

1. Поднять сервис `apps/rag` в Docker (compose `rag`, loopback `:18766`)
2. Проиндексировать корпус (`docs/` + корневые md) **двумя** стратегиями:
   - **fixed** — окна ~800 символов, overlap ~120
   - **structural** — по заголовкам / файлам
3. У каждого чанка должны быть: `source`, `title`, `section`, `chunk_id`, `strategy`
4. Записать сравнение (сколько чанков, средний размер) в `RESULTS.md`
5. На сайте: **Профиль** → блок «База знаний стенда» (чанки / стратегия видны)

Эмбеддинги по умолчанию через API; локальная модель — только admin, по умолчанию выкл.
