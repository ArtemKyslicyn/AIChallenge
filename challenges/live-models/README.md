# Живой выбор модели (опционально, вне сетки 21–25)

**Цель:** в обычном чате выбрать живую модель с пульса стенда и получить ответ с тем же `model_id`. Старую вкладку MCP не ломать.

Это **не** день 21 курса (день 21 = индексация в [`../21-rag-index`](../21-rag-index/)).

## Что сделать

1. Открой https://aichallenge.arcilite.ru/?shell=chat → **Новый чат**
2. Карточка «Кому писать сейчас» → **Писать {модель}**
3. Селект модели ≠ «Авто»
4. Сообщение «назови свой model_id» → badge = тот же id
5. Вкладка **MCP** жива (дни 16–20)
