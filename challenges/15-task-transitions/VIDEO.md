# Текст видео — День 15. Контролируемые переходы

~2:30. Экран: Агенты → полоса Задача. Граф: planning → execution → validation → done.

---

«День пятнадцатый. У задачи явный граф. Ассистент не прыгает через ступень.

Старт — этап planning. Смотрим полосу: дальше только execution. Читаем план.

Клик в done из плана — отказ. Перехода нет в графе. Этап не сменился.

Чат «пиши код» на planning — отказ без LLM. Реализация до утверждённого плана запрещена.

Разрешённый переход в execution. Читаем, что сделано на этом этапе.

«Сразу финал без проверки» — отказ. Финал только после валидации.

Пауза. Все переходы закрыты. «Пиши код дальше» — отказ, сначала продолжи.

Продолжить: тот же execution. Читаем продолжение, план не пересказан.

Дальше — validation. Читаем проверку.

Дальше — done. Итог. Жизненный цикл закрыт.»
