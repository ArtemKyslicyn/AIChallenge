# Challenge 05 — Версии моделей (День 5)

Один запрос на **слабой / средней / сильной** модели (начало / середина / конец каталога).

Замеры: время, токены≈, cost≈; сравнение качества / скорости / ресурсоёмкости.

## На платформе

1. https://aichallenge.arcilite.ru/ → FAB **Модели** → вкладка **Студия**
2. Промпт из `prompt.txt`, пики по умолчанию, **Запустить**
3. Сверь метрики с `RESULTS.md`

## Код / автопрогон

```bash
python3 challenges/05-model-tiers/run.py
```

Артефакты: `results.json`, `RESULTS.md`, видео `challenge-05.webm`.

Формат сдачи: **Видео + Код**.
