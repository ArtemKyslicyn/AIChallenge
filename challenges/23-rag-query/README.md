# День 23 — Вопрос к базе: с RAG и без

**Цель:** один и тот же вопрос без базы и с базой; с базой — ответ опирается на индекс и показывает источники. Загрузка своего файла видна в чате.

## Что сделать

1. Открой чат → **Настройки**
2. **Без базы:** сними галочку «Использовать базу» → спроси:  
   «Куда ходит публичный :443 на этом стенде?»  
   → ответ без блока «Источники базы»
3. **С базой:** включи галочку → тот же вопрос  
   → ответ по docs + раскрываемые «Источники базы» + бейдж `model_id`
4. **Загрузка:** кнопка **«В базу»** / **«Добавить в базу»** → в ленте:
   - раскрывающаяся карточка `rag_ingest` (имя, чанки, preview)
   - короткий ответ ассистента «принял документ… о чём он»
5. Кнопка **«Документы»** → карточка `rag_list_documents` со **своими** загрузками
6. Подготовь **10 контрольных вопросов** — [`QUESTIONS.md`](QUESTIONS.md)

Опционально: внешний RAG через Guest MCP (не стендовый `/mcp/*`).
