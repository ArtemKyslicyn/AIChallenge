# День 23 — план съёмки (максимум по домашке)

Цель ролика: за ~2–3 минуты проверяющий **без README** видит все критерии PASS.

Сайт: https://aichallenge.arcilite.ru/?shell=chat  
Авто: `cd challenges/record && RECORD_ONLY=23 npm run record`  
Ручной дубль — если авто не поймал карточку/саммари.

## Перед записью

1. Прод уже с фичей upload-карточек (после деплоя `b2b9bda+`).
2. **Новый чат** (пустая лента).
3. Подготовить маленький файл `day23-sample.md` (2–3 абзаца со своей темой — не из стендового корпуса).
4. Зум/оверлеи как в `record.mjs` (карточки дня читаемы).

## Раскадровка (обязательные биты)

| # | Длительность | Действие на экране | Что доказывает |
|---|--------------|--------------------|----------------|
| 0 | 5–7 с | Титр: «День 23 · Ask ± база · upload · список docs» | контекст |
| 1 | 20–30 с | Настройки → **снять** «Использовать базу» → вопрос `:443` → ответ **без** «Источники базы» | ask без RAG |
| 2 | 25–35 с | Включить базу · режим **full** → тот же вопрос → раскрыть «Источники базы» + badge `model_id` | ask с RAG + источники |
| 3 | 35–50 с | **В базу** ← `day23-sample.md` → дождаться: (a) открытая карточка `rag_ingest` (имя, +N чанков, preview), (b) bubble ассистента «принял… о чём…» с `model_id` | upload выполнен и понятен |
| 4 | 20–30 с | Кнопка **Документы** → карточка `rag_list_documents` со своим файлом | tool списка (только свои) |
| 5 | 10–15 с | (Опц.) задать вопрос **по тексту загруженного файла** → в источниках виден `day23-sample` | файл реально в поиске |
| 6 | 5 с | Титр: «QUESTIONS.md — 10 вопросов отдельно» | полный список не в ролике |

Итого целевой хронометраж: **~2:00–2:40**. Не растягивать паузы после ответа >8 с.

## Что крупно в кадре

- Галочка «Использовать базу» on/off — не мельком.
- Блок **Источники базы** раскрыт (title · section · source · score).
- Карточка tool: `summary` виден, `preview` читаем (не только заголовок).
- Бейдж `model_id` на саммари после upload и на grounded-ответе.

## Чего не снимать

- Полный прогон всех 10 вопросов из `QUESTIONS.md` (текст в репо).
- Terminal / reindex / Docker.
- Вкладку MCP и Guest MCP (достаточно фразы в RESULTS: documented).
- Админский «Все документы» — только если явно показываешь роль админа (отдельный титр).

## Критерий «ролик готов»

Чеклист `RESULTS.md` строки 1–4 и 6–8 закрываются **только кадрами**, без устных пояснений.  
После записи: обновить `challenge-23.mp4` / `.webm`, в RESULTS убрать пометку «видео после деплоя».

## Авто vs ручное

| | Авто `record.mjs` | Ручное |
|---|---|---|
| Стабильность | титры + паузы | можно дольше подержать preview |
| Upload | `setInputFiles` sample md | свой осмысленный файл |
| Саммари | ждёт `.turn.assistant` | убедиться, что не fallback «local-preview» |

Рекомендация: сначала авто; если саммари упало в fallback — один ручной дубль бита 3–4.
