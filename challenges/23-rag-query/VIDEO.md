# Challenge 23 — видео (RAG-запрос / дни 22)

Сайт: https://aichallenge.arcilite.ru/  
Не показывать токены. Не затирать чужие ролики.

## Сценарий (~3–4 мин)

1. Новый обычный чат. **Ещё** → галочка **«Использовать базу»** выкл.  
   Вопрос из `QUESTIONS.md` №3 или №2 (Guest MCP / :443). Дождаться ответа — **без** блока источников.
2. **Ещё** → включить **«Использовать базу»**. Индикатор **База** у mode-ряда.  
   Тот же вопрос. Под ответом раскрыть **«Источники базы»** (title / section / source / chunk_id).  
   Крупно `model_id` под ответом.
3. Кнопка **Файл** → загрузить короткий `.md` со своим фактом → статус «в базе · N чанков».  
   Спросить по этому факту с базой вкл — источник указывает на upload.
4. (Опционально) Профиль → Подключения: stats стенда; фраза про внешний RAG через Guest MCP `/mcp`.  
   Admin toggle локальных эмбеддингов **не включать** на проде в ролике (оставить выкл).

## Кадр-итог

Два ответа рядом по смыслу: без RAG vs с RAG + источники. Список из 10 контрольных — `QUESTIONS.md`.
