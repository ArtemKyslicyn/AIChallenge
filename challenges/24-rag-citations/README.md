# День 24 — Цитаты, источники и анти-галлюцинации

**Цель:** ответ всегда с источниками и цитатами; при слабой релевантности — «не знаю» и просьба уточнить.

Папка: `24-rag-citations` = **день 24** домашки.

## Что сделать

1. Включи базу знаний в чате
2. Задай вопрос по корпусу → в ответе должны быть:
   - текст ответа
   - список источников (`source` + `section` / `chunk_id`)
   - **цитаты** (фрагменты чанков в UI)
3. Проверь на **10 вопросах** ([`QUESTIONS.md`](QUESTIONS.md)):
   - есть ли источники
   - есть ли цитаты
   - совпадает ли смысл ответа с цитатами
4. Усиление: если релевантность ниже порога / фрагментов нет — ассистент говорит **«не знаю по базе»** и просит уточнение (не выдумывает)

Код: `format_rag_system_context`, UI `rag-sources-quote`, режимы filter в `apps/rag`.
