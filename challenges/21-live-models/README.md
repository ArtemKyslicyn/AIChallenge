# День 21 — живой выбор модели в чате

**Артефакты:** `challenge-21.mp4` · `VIDEO.md` · `RESULTS.md` · `DAYS.md`

## Требование задания

Пустой чат предлагает **живую** модель с пульса стенда. Кнопка **Писать {модель}** ставит пин. Под ответом виден тот же `model_id`. Вкладка MCP и дни 16–20 не ломаются.

## Где смотреть

| Что проверить | Где |
|---|---|
| Карточка «Кому писать сейчас» | `?shell=chat`, новый чат |
| Пин модели | кнопка **Писать …** → селект ≠ Авто |
| `model_id` под ответом | бейдж на bubble ассистента |
| MCP цел | вкладка **MCP** |
| Код | `apps/web` LiveWho / composer model picker; API live pulse |
