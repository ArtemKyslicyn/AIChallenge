# День 21 — Живой выбор модели в чате

**Цель:** в обычном чате выбрать живую модель с пульса стенда и получить ответ с тем же `model_id`. Старую вкладку MCP не ломать.

## Что сделать

1. Открой https://aichallenge.arcilite.ru/?shell=chat → **Новый чат**
2. На карточке «Кому писать сейчас» сними пульс (если нужно) и нажми **Писать {модель}**
3. Убедись, что в селекте модели не «Авто», а выбранный id
4. Отправь короткое сообщение («назови свой model_id»)
5. Под ответом ассистента бейдж = тот же id
6. Открой вкладку **MCP** — она жива (дни 16–20 не снесены)
