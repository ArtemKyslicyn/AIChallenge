# Challenge 21 — живой выбор модели

Пульс `model_pulse` приходит в обычный чат. Полоска **Живые модели** делит каталог на «брать» и «не брать». Клик по живой чипсе ставит пин в композиторе. Вкладка MCP и дни 16–20 не тронуты.

## На платформе

1. https://aichallenge.arcilite.ru/?shell=chat
2. Композитор: **Снять пульс**
3. Чип `брать` → модель в селекте; чип `не брать` выключен
