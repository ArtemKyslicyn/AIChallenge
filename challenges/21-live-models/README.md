# Challenge 21 — кому писать сейчас

Пустой чат предлагает живую модель с пульса стенда. Кнопка **Писать {модель}** ставит пин. Под ответом виден `model_id`. Вкладка MCP и дни 16–20 не снесены.

## На платформе

1. https://aichallenge.arcilite.ru/?shell=chat
2. Новый чат → карточка **Кому писать сейчас**
3. **Писать …** → селект модели → сообщение
