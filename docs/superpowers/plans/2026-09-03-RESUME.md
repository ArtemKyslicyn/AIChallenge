## Как поднять стенд для ревью заново

Он снесён (одноразовый Postgres, свой API и Vite). Дев-compose пользователя не трогали.

```bash
docker run -d --name aic-ux-db \
  -e POSTGRES_USER=uxrev -e POSTGRES_PASSWORD=uxrev-local-only -e POSTGRES_DB=uxrev \
  -p 55434:5432 postgres:16

cd apps/api
DATABASE_URL="postgresql+asyncpg://uxrev:uxrev-local-only@localhost:55434/uxrev" \
  uv run alembic upgrade head

DATABASE_URL="postgresql+asyncpg://uxrev:uxrev-local-only@localhost:55434/uxrev" \
USE_FAKE_LLM=true RUN_TRACE_ENABLED=true \
LLM_MODEL_CHAIN="fast-mini,balanced-pro,deep-reasoner-preview-2026-08,tiny-draft" \
MODEL_COST_PROXY_JSON='{"fast-mini":0.2,"balanced-pro":1.0,"deep-reasoner-preview-2026-08":4.5,"tiny-draft":0.1}' \
FEEDBACK_MIN_VOTES=2 CORS_ALLOW_ORIGINS="http://localhost:5174" \
  uv run uvicorn app.main:app --host 127.0.0.1 --port 8099 &

cd ../web && VITE_API_URL="http://localhost:8099/api/v1" npx vite --port 5174 --strictPort &
```

Наполнить данными обязательно — пустые таблицы нечего ревьюить: создать сессию, отправить
несколько сообщений с разными пинами моделей, поставить пару 👍/👎. FakeLLM отвечает мгновенно,
поэтому `p50` будет околонулевым; для разговора про latency значения правились SQL-апдейтом
по `run_traces`.

Порты, которые были заняты чужим: **8000** (дев-compose пользователя). Не занимать.
