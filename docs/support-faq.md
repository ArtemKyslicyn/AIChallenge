# FAQ поддержки стенда

Для режима **Ассистенты → Поддержка**. Без секретов и ПДн.

## Сессия и «авторизация»

- Гостевой чат: при открытии создаётся сессия; заголовок `X-Session-Token`.
- Вход в профиль (email) нужен для Guest MCP, local LLM pin и персональных подключений.
- Если «не работает авторизация»: обновите страницу; при 443-таймауте откройте `:8443` (см. `stand-edge-ports.md`).

## База знаний (RAG)

- В чате: режим базы / toggle RAG. Пустые источники → «не знаю по базе», не выдумывать.
- Вкладка **База** — мини-чат с источниками и памятью задачи (день 25).
- Справка по проекту — вкладка **Ассистенты → Справка** (только handbook-корпус).

## Лимиты (429)

- Agent workshop и local LLM могут отдавать 429 при превышении rate limit.
- Подождите и повторите; не крутите ключи в чате.

## Local LLM (Ollama)

- Профиль → Local LLM: URL и модель; allowlist email/origin на API.
- Без allowlist опасные фичи закрыты. См. `docs/env-local.md` (имена переменных, не значения).

## Свой MCP (Guest MCP)

- Нужен вход. Подключения: URL Streamable HTTP + Bearer (туннель с ноутбука).
- Stdio с ноутбука напрямую в облако не ходит — используйте `aichallenge-mcp-kit` + cloudflared.
- В чате можно отключить «Свой сервер в этом чате», не удаляя URL.

## Тикеты

- Демо-тикеты синтетические (`data/support/`). Не кладите реальные email и токены.
- Нет уверенности по FAQ → эскалация / создание тикета, не выдуманный workaround.
