LLM-bound conflict simulation board. Visualization is a projection of structured world state. Practices from WarAgent, WarGames, multi-agent simulation engines, and geopolitical LLM demos. Demo turn uses embedded illustrative decisions, not a live model call.

LLM conflict emulation board

State → briefing → country agents → game master → cascades → viz. Prior graphs kept.

Pipeline (GitHub practices)

  1. Briefing / fog of war per country agent
  2. Faction debate optional (hawk / dove / realist)
  3. Structured action space only
  4. Secretary / schema validate
  5. Game master deterministic resolve
  6. Cascades: oil · shipping · sanctions · morale
  7. Narrator recap separate from decision agents
  8. Export JSON → drive globe / arcs / meters
